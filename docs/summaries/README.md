# GitHub Pages — Summary PDFs

This directory holds the chapter summary PDFs displayed in the embedded PDF viewer at the top of each chapter page.

## Naming Convention

| File | Chapter |
|------|---------|
| `ch1_summary.pdf` | C++ Fundamentals for Robotics |
| `ch2_summary.pdf` | ROS 2 Architecture & Middleware |
| `ch3_summary.pdf` | Flight Controllers & Simulation |
| `ch4_summary.pdf` | UAV Communication (MAVLink & MAVSDK) |
| `ch5_summary.pdf` | Bridge: ROS 2 meets PX4 |
| `ch6_summary.pdf` | AI & Computer Vision |
| `ch7_summary.pdf` | Deployment & Containerization |

## How to Create a Summary

Write your chapter summary as LaTeX, compile to PDF, and place it here with the correct filename.
The site's PDF viewer will automatically pick it up.
